# cocoChloe

Coco‘s random thoughts, published as a pure static personal site.

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`. The root page links to `/zh/` and `/en/`.

## GitHub Pages

This repository is ready for GitHub Pages static hosting from the `main` branch and `/root` folder.

1. Push the repository to GitHub.
2. Open **Settings -> Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select **Branch: main** and **Folder: /root**.

No build step is required.
